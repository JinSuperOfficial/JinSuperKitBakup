## 二、UI 布局（对标 GeoGebra Graphing Calculator）

### 2.1 整体布局

采用 GeoGebra 的经典布局结构：

```
┌─────────────────────────────────────────────────────┐
│  菜单栏  │  标题  │  撤销/重做  │  设置  │  视图切换  │
├─────────────────────────────────────────────────────┤
│  工具栏（Toolbar）— 移动、点、线、线段、多边形等工具  │
├──────────────────────┬──────────────────────────────┤
│                      │                              │
│   代数区              │      绘图区                   │
│   （Algebra View）    │      （Graphics View）        │
│                      │                              │
│   ┌──────────────┐   │   ┌──────────────────────┐   │
│   │ 输入栏        │   │   │  坐标轴 + 网格        │   │
│   │ (Input Bar)   │   │   │                      │   │
│   └──────────────┘   │   │  函数图像 / 点 / 线    │   │
│                      │   │                      │   │
│   表达式列表          │   └──────────────────────┘   │
│   • f(x) = x²        │                              │
│   • A = (1, 2)       │                              │
│   • 线段 [A, B]       │                              │
│                      │                              │
├──────────────────────┴──────────────────────────────┤
│  表格区（TableView）— 函数数值表 / 点列表             │
└─────────────────────────────────────────────────────┘
```

**布局规则：**
- 左侧为**代数区（Algebra View）**，宽度约占 30%，包含输入栏和表达式列表。
- 右侧为**绘图区（Graphics View）**，宽度约占 70%，显示坐标轴、网格和所有图形对象。
- 顶部为**菜单栏 + 工具栏**，工具栏包含几何工具（移动、点、直线、线段、垂线、多边形等）。
- 底部可展开**表格区（TableView）**，显示函数的数值表或点的坐标列表。
- 所有视图**动态联动**：在代数区修改表达式，绘图区实时更新；在绘图区拖动点，代数区坐标实时变化。

| 工具组 | 工具 |
| :--- | :--- |
| 移动 | 选择 / 移动对象 |

### 2.4 输入栏（Input Bar）

输入栏嵌于代数区底部（Web 版布局），支持：
- 直接输入函数表达式（如 `f(x) = x^2`、`sin(x)`、`x^3 - 2x + 1`）
- 输入点坐标（如 `A = (1, 2)`）
- 输入几何对象命令（如 `Segment(A, B)`、`Line(A, B)`）
- 输入后按 Enter 执行，图形立即在绘图区显示

## 三、核心功能

### 3.1 函数绘图

支持标准数学函数输入与绘制，包括：
- 多项式、三角函数、指数函数、对数函数、绝对值函数
- 分段函数（如 `f(x) = If(x < 0, -x, x)`）
- 参数方程（如 `Curve(cos(t), sin(t), t, 0, 2π)`）
- 隐函数（如 `x^2 + y^2 = 1`）

输入 `f(x) = ...` 后，绘图区自动生成函数曲线，代数区显示函数表达式。

### 3.2 表达式 ↔ 图形双向解析

**（a）从表达式解析图形**
- 在输入栏输入表达式 → 绘图区自动绘制对应图形。

**（b）从图形反解析表达式**
- 用户点击绘图区中已有的**函数曲线** → 系统尝试推断其数学表达式，并显示在代数区中。
- 支持从**直线**反解析出线性方程（如 `y = 2x + 1`）。
- 支持从**圆**反解析出圆方程（如 `(x-1)² + (y-2)² = 4`）。
- 若无法精确解析，则给出近似表达式或提示“无法解析”。

### 3.3 点表格 ↔ 图形双向解析

**（a）从点表格解析点**
- 表格区中显示的坐标点（如 `(1, 2)`、`(3, -1)`），用户点击某一行 → 绘图区中对应的点高亮显示。
- 支持在表格中直接编辑点的坐标，绘图区实时更新。

**（b）从图形解析点**
- 用户点击绘图区中的**点对象** → 代数区和表格区同步显示该点的坐标。
- 支持拖动点，坐标实时更新到表格和代数区。

### 3.4 线段 / 线标注

**（a）在图上标出点**
- 使用“点”工具在绘图区任意位置创建点，自动生成坐标标签（如 `A = (1.5, 2.3)`）。

**（b）在图上标出线段 / 线**
- 使用“线段”工具：依次点击两个点（或点击两点创建线段），生成线段 `[A, B]`，代数区显示 `Segment(A, B)`。
- 使用“直线”工具：点击两点创建无限延伸的直线。
- 支持**定长线段**：点击一个点，输入长度，生成线段。
- 所有线段/线在代数区有对应的代数表示，支持修改端点坐标后线段自动更新。

### 3.5 表格区（TableView）

- 当函数被激活数值表时，表格区显示 9 组 x-y 对应值。
- 表格中的点可点击，对应绘图区中的点高亮。
- 支持从表格数据生成点列表或折线。

## 四、主题系统

### 4.1 主题切换

提供三套主题，通过顶部菜单或设置面板切换：

| 主题 | 说明 |
| :--- | :--- |
| **亮色（瑞士国际主义）** | 默认主题，纸白底 + 墨黑字 + 克莱因蓝强调 |
| **暗色（瑞士国际主义暗色版）** | 深色底 + 浅色字 + 橙色强调 |
| **绿色模式** | 以绿色为强调色的衍生主题 |

### 4.2 亮色主题（瑞士国际主义）

严格遵循瑞士国际主义风格：**高级灰白底 + 单一高饱和高亮色**，不允许混搭多个高亮色。

```css
:root[data-theme="swiss-light"] {
  --paper:      #FAFAF8;   /* 纸白 — 页面背景 */
  --ink:        #0A0A0A;   /* 墨黑 — 正文/标题 */
  --grey-1:     #F0F0EE;   /* 浅灰 — 卡片底 */
  --grey-2:     #D4D4D2;   /* 中灰 — 分隔线 */
  --grey-3:     #737373;   /* 暗灰 — 辅助文字 */
  --accent:     #002FA7;   /* 克莱因蓝 — 强调色 */
  --accent-on:  #FFFFFF;   /* 强调色上的文字 */
}
```

**排版规则：**
- 字体：IBM Plex Sans（备选：Hanken Grotesk / Barlow / DM Sans）
- 12 列网格，8px 基础单位
- 正文最大宽度 60ch
- 层级通过**透明度**而非色相区分（如 `text-stone-900/70`）

### 4.3 暗色主题（瑞士国际主义暗色版）

“纸和墨对调”：深色纸 + 浅色墨 + 橙色强调。

```css
:root[data-theme="swiss-dark"] {
  --paper:      #0F1012;   /* 深色纸 — 页面背景 */
  --ink:        #F1F1EC;   /* 浅色墨 — 正文/标题 */
  --grey-1:     #1A1B1F;   /* 深灰 — 卡片底 */
  --grey-2:     #26282D;   /* 中灰 — 分隔线 */
  --grey-3:     #8B8E97;   /* 灰 — 辅助文字 */
  --accent:     #F97316;   /* 橙色 — 强调色 */
  --accent-on:  #0F1012;   /* 强调色上的文字 */
}
```

### 4.4 绿色模式

以绿色为强调色的衍生主题，保留瑞士风格的灰白基底：

```css
:root[data-theme="swiss-green"] {
  --paper:      #F7FAF5;   /* 微绿纸白 */
  --ink:        #0A0A0A;   /* 墨黑 */
  --grey-1:     #EDF2EA;   /* 浅绿灰 */
  --grey-2:     #D0DAC9;   /* 中绿灰 */
  --grey-3:     #6B7A63;   /* 暗绿灰 */
  --accent:     #2D6A4F;   /* 深绿 — 强调色 */
  --accent-on:  #FFFFFF;
}
```

### 4.5 主题切换规则

- 切换主题时，**所有颜色 token 同步替换**，包括代数区背景、绘图区网格、坐标轴、函数曲线颜色、工具栏图标。
- 暗色主题下，绘图区背景自动切换为深色，网格线变为白色半透明，坐标轴标签变为浅色。
- 亮色主题为**默认主题**。

在顶部菜单栏增加 **「更多811工具」** 按钮，点击后打开工具集面板，支持：
- 展示其他 811 工具的入口列表（以卡片形式排列，每张卡片显示工具名称、图标和简要说明）。

- 将数据同步到其他 811 工具。
- 支持反向导入：从其他 811 工具导入表达式或点数据，自动在 Plot 图像计算器中渲染。
