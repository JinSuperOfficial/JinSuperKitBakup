访问方式（要不要备案）

Gitee 走的是国内域名，**不需要备案**；只有当你把镜像挂到自己的域名 / 国内对象存储的自定义域名上，才要办 ICP 备案。

备案怎么办（只在你选了自定义域名时才需要）
  • 前提：域名已实名、挂在境内服务器或境内对象存储上；
  • 材料：主体证件、域名证书、负责人照片、网站备案信息表；
  • 入口：工信部备案系统（下面按钮打开），一般 7–20 个工作日；
  • 没备案也能用：保持「Gitee（免备案）」这一项就行。
