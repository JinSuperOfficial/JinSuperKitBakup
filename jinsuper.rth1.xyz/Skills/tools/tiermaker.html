从夯到拉生成器

拖一拖，排个等级榜
预设
把图片拖到任意等级；右键（手机上长按）改大小；键盘 ←→↑↓ 移动，Delete 删除。

设置

预设配色

三套预设：A 经典是参考图的色号，B 冷调和 C 品红按项目主题规范另配。切换会覆盖下面的标签和颜色，之后仍可随便改（改了会标成「自定义」）。

标签文字风格

同一套配色下，等级名可以写「夯～拉完了」，也可以改用编号 T0～T4。

等级标签与配色

改文字或颜色会立刻生效（不用点保存）。左侧小方块是预览。

网格吸附

0 表示不吸附、自由摆放。拖动时画面上会出现同间距的参考点，小方块会吸到最近的点上。

粘贴 SVG 代码

把 <svg>…</svg> 整段贴进来，会加进底部备选栏。

存档

配置和素材存在本机浏览器里。换设备 / 清缓存前先导出一份 JSON。
