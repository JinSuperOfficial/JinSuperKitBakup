关于这个画面

这是鹈鹕测试的一份答卷——一只戴头盔、系围巾的鹈鹕，骑着青绿色自行车沿海岸前进。 画面里的所有元素都是纯 SVG 绘制，动画由 CSS 变量和 JavaScript 驱动，没有任何外部素材。

骑行本身用了几个小技巧：车轮旋转的角度同时驱动地面位移， 位移量等于 角度 × 车轮半径，所以视觉效果是「轮子转多少，地面就走多少」。 两条腿用逆向运动学反解膝盖位置， 上下两个踏板各占半圈，踩踏动作是物理正确的。

海岸、云、草丛都用 <use> 复用同一小段 tile，两段错位拼接循环滚动，无缝衔接。 支持 0.5× / 1× / 1.5× 调速、暂停播放、遵循系统的减少动态效果偏好。

灵感来自 Simon Willison 的鹈鹕基准测试。
