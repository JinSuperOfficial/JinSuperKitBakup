## 一、暖调·大地系

**适合场景**：家居、生活方式、茶品牌、自然/环保、咖啡、手作品牌、有机产品

**1. 大地暖调**（来源：Framer Sereenity 模板）

| 角色 | 色名 | HEX |
| :--- | :--- | :--- |
| 背景 | 暖米色 | `#F8F3EC` |
| 主色 | 橄榄绿 | `#8E9867` |
| 强调色 | 陶土橙（接近 Claude 橙） | `#E1937D` |
| 文字/辅助 | 橡木棕 | `#8D6959` |

> 这组配色天然契合 better-theme 的“暖调 + Claude 橙”主线。陶土橙与 Claude 橙 `#D97757` 属同一色系，可以互换使用。

**2. 暖中性棕**（来源：Framer Harper 模板）

| 角色 | 色名 | HEX |
| :--- | :--- | :--- |
| 背景 | 奶油色 | `#FFF3DB` |
| 主色 | 皮革棕 | `#51301F` |
| 辅助色 | 赤褐色 | `#7A3110` |
| 强调色 | 卡布奇诺 | `#AA8867` |

> 适合高端手作、精品咖啡、复古品牌。棕色系作为主色调时，文字用深棕代替纯黑会更协调。

**3. 现代暖调**（来源：DepositPhotos 2026 春季趋势）

| 强调色 | 薄荷蓝 | `#7EC8C8`（近似 Mint Blue） |

## 二、冷调·自然系

**适合场景**：科技、工具类产品、开发者文档、环保科技、医疗健康、SaaS 后台

**1. 墨绿系**（来源：Framer Hydra 模板）

| 角色 | 色名 | HEX |
| :--- | :--- | :--- |
| 背景 | 雾灰 | `#E9E9E9` |
| 主色 | 深青 | `#122023` |
| 强调色 | 青柠 | `#E1FCAD` |
| 辅助深色 | 深海蓝 | `#1E1E1F` |

> 深青代替纯黑作为主色，青柠作为唯一的亮色点缀。适合科技感但不想太冷的产品页面，深青的暖调让整体不会过于冰冷。

**2. 2026 夏季功能系**（来源：DepositPhotos 2026 夏季趋势）

| 角色 | 色名 | HEX |
| :--- | :--- | :--- |
| 背景/结构 | 混凝土灰 | `#D5D5D7` |
| 主色 | 泳池蓝 | `#539DB6` |
| 强调色 | 酸性绿 | `#AEB73A` |
| CTA/紧急 | 日落橙 | `#FF5F21` |

## ⚠️ 使用注意

1. **本文件是决策参考库，不是固定模板**。Claude 应根据页面主题、行业、受众和情绪主动选用，不需要等用户点名。
2. **硬规则优先于本文件**：严禁蓝紫渐变、红绿渐变、紫/靛渐变作为主色调；正文与背景对比度至少 4.5:1；主色不超过 3 种，按 60-30-10 控制比例。
3. **色值可微调**：部分色值是根据原文描述推荐的近似值（标注“推荐近似值”的），并非原文直接给出的 HEX。使用时可根据实际效果调整。
4. **优先使用 Claude 橙**：`#D97757` 仍是 better-theme 的默认强调色。本文件中的其他橙色方案仅在场景匹配时作为替代选项。
