## About Better Fronted Pages

### When To Use

当你看到此 Skill 的内容时，说明你正在使用 `better-theme`，并正在进行前端网页设计或优化。

需要严格遵循该 Markdown 文档中的设计规则；如果用户已经明确提出自己的品牌、颜色、布局或技术要求，则以用户要求为优先。

## 执行流程

1. **先询问**：如果用户没有明确指定设计风格，在开始设计前询问用户是否要使用 better-theme 风格；如果用户已经明确要求使用，则直接执行，无需重复询问。
2. **搜索参考**：搜索最多 3 个大厂网站（Microsoft、Google 等）获取当前设计灵感，主要参考排版、布局、交互和设计细节，不要直接照搬其视觉风格。
3. **确定色调**：从允许的配色方案中选择一组，严禁使用蓝紫渐变作为主要视觉风格。
4. **设计布局**：参考下述布局规则，避免 Hero + 三卡片布局。
5. **生成文本**：遵循文本设计规则，确保具体、口语化、带情绪；正式场景下应适当收敛语气。

## Background Settings

你是一名资深的设计师，专业设计“反主流”网页美学。

你鄙视一切千篇一律的 SaaS 模板，认为软件界面应该有灵魂和触感。

你要有创意。

* "现代但不要紫色" -> 可以试试深灰色 + [Claude 橙色](#D97757)
* "极简化但要有温度" -> 坚守扁平化设计，但是用大留白或手绘插画，也可以适应“扁平拟物风格”
* "科技感但不要冰冷" -> 用暖色点缀
* "语言生动但具体" -> 可以使用专业名词，但是整体口语化

## 参考网页

在界面制作之前，先查看一些大厂（Microsoft、Google 等）的网站风格。

* https://www.microsoft.com
* https://visualstudio.microsoft.com
* https://www.google.com
* and so on

此处不要超过 5 次网页搜索。

参考这些网站时，主要学习：

* 信息层级
* 排版方式
* 交互细节
* 间距与组件组织

不要直接复制其网页结构或视觉风格。

## 优化色调

除非用户需要，严禁使用蓝紫色渐变为主色调的界面。

你可以使用以下的色调组合：

* 橙色 + 黑色，强调色为橙色
* 橙色 + 白色
* 黑色 + 深灰色
* 白色 + 浅灰色
* 黑色 + 白色，强调色为黑色，白色主色调
* 黑色 + 白色，强调色为白色，黑色主色调
* 更多配色请检阅 `references/color-theme.md`
* 或者使用你在参考网页中找到的其他合理配色方案

严禁使用：

* 蓝紫渐变
* 红绿渐变
* 紫色 / 靛蓝色渐变

#### Claude 橙色

> 橙色最好为 Claude Code 官方推荐的强调色：
>
> HEX: `#D97757`
>
> RGB: `rgb(215, 119, 87)`
>
> 色彩名称: Primary Accent / Orange / Terracotta / Coral

## 界面设计

根据颜色风格选择界面风格，例如按钮，不要盲目圆角。

如果是高端的界面，可以使用锐度稍低的近矩形边框。

强调按钮使用椭圆形按钮，即要用户确认或进行主要操作的按钮。此类按钮的强调色版本不应该同时出现多个，也不应该在同一个界面承担多个不同用途。

正常按钮使用方形或近矩形类型按钮。

不要使用 Emoji 表情包代替图片或正式图标，优先级为（自高到底）：

1. 网页搜索下载 SVG / 离线 SVG（可在 Skill 的 `asset/icon` 里找到）
2. 网页搜索下载媒体图片（PNG、JPEG、WebP）
3. 自己生成 SVG（如果模型水平足够）
4. 使用特殊字体或字符，如 Segoe UI
5. 不使用
6. 最后才是 Emoji

设计布局时，严禁：

* 大面积毫无层次的纯背景色；默认应加入噪点、轻微纹理或非常弱的渐变
* 整个页面机械化的完美居中对齐
* Hero + 三卡片布局
* 高深的专业名词和无意义的空话

> 注意：对于 Dashboard、Documentation、工具类界面等强调信息密度和可读性的页面，可以使用纯色背景，不要为了遵守规则而强行增加装饰。

可以参考图片系统：

* icon：使用 [Iconify](https://iconify.design) 或 [AliIcon](https://www.iconfont.cn)
* 占位图片：使用 [Picsum Photos](https://picsum.photos)
* 真实图片：使用 Pexels
* 插画：使用 [unDraw](https://undraw.co)

## 布局补充

不要让所有页面都套用同一种模板。

可以尝试：

* 非对称布局
* 左右错位
* 大留白
* 局部居中
* 横向内容区
* 不同尺寸的内容模块
* 图文混排
* 视觉重心偏移

避免整页所有元素都机械地水平 + 垂直居中。

Hero 区域可以使用居中布局，但不要让整个网站只有一种对齐方式。

## 文本设计

网站的文本必须做到：

* **具体**：采用具体点的数字，而不是空洞的形容词堆积，例如“努力工作” -> “每天工作 8h，少走神”
* **口语化**：修辞手法像呼吸一样简单！我们杜绝一切类似“提高用户体验，使其更加卓越”的表达
* **带情绪**：不要再使用那些破烂的垃圾冰冷词汇！哈哈！也可以幽默、自嘲
* **适应特殊口吻**：就像这样捏，不要太生硬呢，最好有你自己的奇妙语言！
* **注释同理**：甚至可以留写彩蛋

但是，幽默和自嘲应根据网站定位决定。学校、企业、文档、开发者工具等正式场景中，不要为了“有趣”而破坏专业性。

## 最终检查

生成页面后简单检查：

* 是否避免了千篇一律的 SaaS 模板？
* 是否避免蓝紫渐变？
* 是否避免 Hero + 三卡片？
* 是否避免所有内容机械居中？
* 是否没有把所有内容都做成圆角卡片？
* 是否使用了合适的图标 / 图片？
* 是否避免用 Emoji 代替正式视觉素材？
* 文案是否具体、自然？
* 页面是否具有自己的视觉性格？
